# VKR: Инфраструктура автоматизированного развёртывания и мониторинга системы имитационного моделирования транспортных потоков

Данный репозиторий содержит реализацию информационной системы с элементами CI/CD, предназначенной для автоматизации развёртывания и эксплуатации симуляционной модели

## Стек технологий

- **Terraform** — автоматизация создания облачной инфраструктуры в Yandex.Cloud
- **Jenkins** — построение конвейеров CI/CD 
- **Ansible** — настройка программного окружения и сервисов
- **Docker** — сборка образа приложения
- **k3s** — упрощённая версия Kubernetes 
- **Prometheus / Grafana** — сбор и визуализация эксплуатационных метрик
- **Python (Pygame)** — реализация визуальной симуляции
- **noVNC** — удалённый доступ к графическому интерфейсу

## Описание системы

- Создание виртуальных машин в различных зонах Yandex.Cloud
- Установка системных компонентов: Docker, k3s, node_exporter
- Сборка и публикация образа  в Docker Hub
- Развёртывание симуляции на k3s-ноды с доступом через веб-браузер
- Мониторинг состояния узлов с помощью Prometheus и Grafana
